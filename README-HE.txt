ready,set, Marathon! — גרסה 13

עדכון: מכסה קבועה של מספר השאלות בכל תת־נושא.

מה חדש:
- בכל תת־קטגוריה מוצג מראש מספר השאלות המקסימלי, ללא אפשרות לערוך אותו.
- המשתמש מזין רק את מספר התשובות הנכונות בכל תת־קטגוריה.
- מספר התשובות הנכונות מוגבל למכסה של אותה תת־קטגוריה.
- חלוקת ברירת המחדל בפרק מילולי: אנלוגיות 6, השלמת משפטים 3, הבנה והסקה 8, הבנת הנקרא 6.
- חלוקת ברירת המחדל בפרק כמותי: הסקה מתרשימים 4, בעיות 6, אלגברה 5, גיאומטריה 5.
- יתר יכולות גרסה 12 נשמרו: בחירת סוג פרק ופיילוט, שמירת פירוט, ניתוח מצטבר וייצוא CSV.

הבהרות חשובות:
- המכסות הן תצורת ברירת מחדל קבועה באפליקציה לפרק מלא: 23 שאלות מילוליות ו-20 שאלות כמותיות. במבחנים/סימולציות שבהם חלוקת השאלות שונה, יש להתייחס לפירוט תתי־הנושאים כניתוח לפי החלוקה המוגדרת כאן.
- נתוני תתי־הנושאים אינם משנים את הציון הפסיכומטרי ואינם מתווספים לנתון הכללי של הפרק.
- פרק פיילוט נשמר לניתוח אך אינו נכלל בחישוב הציון.
- אפשר להשאיר תתי־נושאים ריקים ולהזין רק נתון כללי לפרק.
- שינוי סוג פרק לאחר הזנת תתי־נושאים מציג בקשת אישור לפני החלפת הקטגוריות.

התקנה:
1. חלץ את קובץ ה-ZIP.
2. העלה את כל הקבצים שבתוך התיקייה לשורש מאגר GitHub הקיים.
3. החלף קבצים בעלי שמות זהים ובצע Commit.
4. אין למחוק נתונים מקומיים או להסיר את ה-PWA.

הנתונים הקיימים נשמרים באותו אתר/דפדפן. מומלץ לייצא גיבוי JSON לפני עדכון. מבנה הנתונים הקודם נשאר נתמך.
