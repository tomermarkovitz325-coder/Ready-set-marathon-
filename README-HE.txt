ready,set, Marathon! — גרסה 9

עדכון: דוח ביצועים אישי לכל סימולציה.

מה חדש:
- פתיחת דוח מלא לכל סימולציה מתוך ההיסטוריה או מתוך מסך הביצועים.
- ציונים מילולי, כמותי, חיבור ואומדן כללי.
- הצגת חישוב הציון והבהרה שאומדן החיבור אינו רשמי.
- פירוט תשובות נכונות ואחוז הצלחה לכל פרק.
- הצגת פרק הפיילוט בנפרד, ללא הכללתו בחישוב.
- זמן סימולציה, חותמות זמן והערות לתחקור.
- אפשרות לעבור לעריכת נתוני הסימולציה מתוך הדוח.

התקנה:
1. חלץ את קובץ ה-ZIP.
2. העלה את כל הקבצים שבתוך התיקייה לשורש מאגר GitHub הקיים.
3. החלף קבצים בעלי שמות זהים ובצע Commit.
4. אין למחוק נתונים מקומיים או להסיר את ה-PWA.

הנתונים הקיימים נשמרים באותו אתר/דפדפן. מומלץ לייצא גיבוי JSON לפני עדכון.
