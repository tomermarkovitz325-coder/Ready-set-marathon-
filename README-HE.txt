ready,set, Marathon! | גרסה 17 | Modern Blue

גרסה 17 היא חבילת הפצה מסודרת של ממשק Modern Blue על בסיס קוד האפליקציה הקיים.

מה כלול:
- עיצוב Modern Blue כחול-לבן, מסך שעון ממוקד וסרגל ניווט תחתון.
- ניווט לשעון, הזנת סימולציה, היסטוריה, ביצועים והגדרות.
- תפריט עליון לכל המסכים הקיימים, כולל נקודות זמן ודוחות.
- התאמה למסכי מובייל, safe-area ומצב כהה.

יכולות הליבה שנשמרו מקוד גרסה 14:
- שעון סימולציה, השהיה, מעבר בין חלקים, נקודות זמן, צלילים ואיפוס.
- הזנת סימולציות בדיעבד, עריכה, מחיקה, היסטוריה ודוחות.
- סוגי פרקים, פרקי פיילוט, תתי-קטגוריות ומכנים דינמיים לכל תת־נושא.
- חישובי ציונים, יעד אישי, ניתוח ביצועים ומגמות.
- ייצוא נתונים, גיבוי JSON ושחזור.
- אותם מפתחות LocalStorage ו-IndexedDB ואותו מבנה נתונים. לא בוצע שינוי בסכמת הנתונים.

שינויים טכניים בגרסה 17:
- עדכון שם מטמון Service Worker ל-ready-set-marathon-v17 כדי לפרסם את קובצי הגרסה החדשה.
- עדכון צבעי theme של manifest ומטא-דאטה לעיצוב Modern Blue.
- שדות נפרדים להזנת תשובות נכונות וסך שאלות בפועל בכל תת־נושא, לכל פרק ולכל סימולציה.
- נתוני מכנה נשמרים בתוך אובייקט תת־הנושא הקיים (total), כך שסימולציות ישנות שומרות את הערכים ההיסטוריים שלהן.
- בדיקת תקינות מוודאת שמספר התשובות הנכונות אינו עולה על סך השאלות וששני השדות מוזנים יחד.
- ליטוש נוסף של שדות ההזנה, היררכיית הפרקים, מרווחים, גבולות ומצבי מיקוד, תוך שמירה על שפת Modern Blue.
- לא שונתה נוסחת הציון הכללי או שיטת שמירת ההיסטוריה והגיבוי.

התקנה:
1. שמור קודם גיבוי JSON מתוך האפליקציה.
2. חלץ את ה-ZIP. ששת הקבצים נמצאים ישירות בשורש הארכיון.
3. העלה את ששת הקבצים לשורש המאגר הקיים ב-GitHub והחלף קבצים בעלי שמות זהים.
4. בצע Commit והמתן לפרסום GitHub Pages.
5. פתח את האתר עם ?v=17 בסוף הכתובת כדי לטעון את הגרסה החדשה.

חשוב: אין למחוק נתוני Safari או להסיר את האפליקציה לצורך העדכון. הנתונים נשמרים מקומית באותו דפדפן ובאותו מקור אתר.
